# Projects

Infrastructure repository for my workspace. Only structure and shared configuration
(`CLAUDE.md` files, templates, `.claude/`) are tracked here.

| Folder       | Purpose                                   |
|--------------|-------------------------------------------|
| `courses/`   | Course projects and assignments           |
| `petrobras/` | UFMG–Petrobras project work (strict flow) |
| `research/`  | Research code and experiments             |
| `sandbox/`   | Scratch space and quick experiments       |

Each second-level folder (e.g. `research/SE3_CBF`) is an independent git repository
with its own remote and is ignored by this repo.
